Full Stack Engineer

Work with Paramount on a defined client or internal engineering priority. The listing describes the team, work, and capabilities required for the role.

Apply for this opportunity All opportunities

Role

Full Stack Engineer, Software & Product Engineering team.

What the role will work on

Web applications, APIs, integrations, and AI features inside client products.

Responsibilities

  • Build web applications, internal tools, and customer portals with the workflows and permissions users need.
  • Develop APIs and integrations that connect business tools, customer data, and external platforms.
  • Add AI features such as search, copilots, and document workflows to existing products.
  • Write tests, set up deployment pipelines, and document the system for handover.
  • Demonstrate working increments and resolve feedback with client product owners.

Relevant experience

  • Production experience with TypeScript or JavaScript, React or Next.js, and a backend such as Node.js or Python.
  • Experience with relational databases, REST APIs, and cloud deployment.
  • Familiarity with integrating AI services into applications.
  • Ownership of features from requirements through release.

Location and working hours

Remote, US only. Working hours overlap with client teams as agreed for each engagement.

How to apply

Submit your profile through the register-interest form with examples of systems you have built or improved. Please exclude confidential client information.
